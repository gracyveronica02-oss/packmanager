A system built for the whole floor

Catch the exception.
Not just the obvious.

Shipping evidence has to start at the source. The system integrates a lightweight visual gate before deeper analysis, reserving human judgment for genuine uncertainty.

01
⌁

Fast visual gate

A lightweight check runs on every captured layer, looking for image quality and content plausibility. Most orders pass instantly.

02
◌

Deep verification

Only boxes that look wrong go to detailed analysis—matching SKU labels, counting items, and flagging occlusion. Cost stays proportional to risk.

03
↗

Human decision

UNCERTAIN never auto-seals. An operator sees the evidence, resolves the case, and logs the decision for future training.

No confident guesses

When the box can't be seen, the system stops.

Occlusion is labeled explicitly. Identity and count confidence are tracked per-item. The system knows what it doesn't know.

    Embed PackManager anywhere

    Add the interactive demo
    to your site.

    PackManager is a standalone widget. Use the public JavaScript API to embed the decision interface on any page.

    Basic embed

    <div id="packmanager-demo"></div>
<script src="https://packmanager.example/widget.js"></script>
<script>
  PackManager.init({
    containerId: 'packmanager-demo'
  });
</script>

    With callbacks

    PackManager.init({
  containerId: 'packmanager-demo',
  onDecision: (orderId, action) => {
    console.log(`Order ${orderId}: ${action}`);
  }
});

    Custom styling

    PackManager.init({
  containerId: 'packmanager-demo',
  theme: {
    primaryColor: '#c6f84b',
    fontFamily: 'Manrope'
  }
});

    API Reference

    PackManager.init(options)

    Options: containerId (required), onDecision (callback), theme (object), orderId (string)

    Returns: Widget instance with .destroy() and .reset() methods

    PackManager.loadStyles()

    Load PackManager styles independently if you're not using the full page
