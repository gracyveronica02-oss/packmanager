# PackManager

PackManager is a polished, responsive submission site for an evidence-first pack-verification workflow.

## Run locally

Open `index.html` in a modern browser. No build step or external packages are required.

## Product principles shown in the site

- Every box gets a lightweight visual check.
- Deeper analysis focuses on exceptions to control cost.
- `UNCERTAIN` boxes never auto-seal.
- Layer-based capture makes occlusion explicit.
- Validation targets are labelled as targets, not production claims.

## Deployment

The project is static and can be deployed through GitHub Pages, Netlify, or Vercel.
